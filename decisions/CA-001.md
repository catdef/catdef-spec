## Rationale

**Version stamp.** A patch communicates "no behavior change required." This proposal introduces a content-sniffing requirement on importers that the prior spec did not explicitly mandate. That is a new conformance expectation, which by the spec's own forward-compatibility rules (value #5) is minor-level. Getting this right sets precedent — CA-002 also hinges on version-stamp semantics, and inconsistent handling here would undercut that proposal.

**Dropping `.catdef`.** Don't add surface area speculatively. A schema-only file has nothing to bundle; sanctioning `.catdef` ZIPs adds a conformance test and MIME entry for a format with no producer. Leaner now, extensible later.

**Everything else.** The analogies, mechanisms, and tolerances in the proposal are sound, and the canonical file has already chosen `.opencatalog` — ratifying this direction unblocks the canonical from "pending guidance" status.
